# 💬 Group Chat App (Real-Time)

A stylish, real-time group chat application built using the **MERN** stack and **Socket.io**. This project allows multiple users to join a chat room and communicate instantly with a modern dark-themed UI.

## 🚀 Live Demo
You can access the live application here: 
**[https://group-chat-box-1.onrender.com](https://group-chat-box-1.onrender.com)**

### **How to Test:**
1.  **Multiple Tabs**: Open the link in multiple browser tabs or on different devices.
2.  **Join**: Enter different usernames in each tab (e.g., "Malar", "Sokka Thangam", "Friend").
3.  **Chat**: Send a message from one tab and watch it appear **instantly** in all other tabs without a page refresh!

## 🛠️ Tech Stack
*   **Frontend**: React.js
*   **Backend**: Node.js, Express.js
*   **Database**: MongoDB
*   **Real-time Engine**: Socket.io
*   **Hosting**: Render

## 📂 Folder Structure
*   `client/`: React frontend source code and assets.
*   `server/`: Node.js backend, API routes, and Socket logic.
